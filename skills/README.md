# Skills da Vizantu

Pasta central das skills (Claude/Agent Skills) da Vizantu. Cada subpasta é uma skill autocontida, com seu `SKILL.md` e os arquivos de apoio (`references/`, `assets/`, `scripts/`).

Para usar localmente, copie a subpasta para `~/.claude/skills/`.

## Skills disponíveis

| Skill | O que faz |
|---|---|
| [`plano-campanha-html`](plano-campanha-html/) | Gera planos de campanha e planos mensais de gestão de marca em HTML único e autocontido, no padrão visual premium da Vizantu — com roteiros verbatim, mockups de Instagram, calendário do mês e integração com a aprovação da plataforma Vizantu Planos. |
