# Marca Vizantu

Ativos oficiais da marca Vizantu (logo: hexágono + wordmark `vizantu®`).

| Arquivo | Uso |
|---|---|
| [`vizantu-logo-branco.svg`](vizantu-logo-branco.svg) | Wordmark **branco** — para fundos escuros. |
| [`vizantu-logo-preto.svg`](vizantu-logo-preto.svg) | Wordmark **preto/escuro** — para fundos claros. |

Cores da marca:
- Roxo claro `#9147FF`
- Roxo `#6435E7`
- Gradiente do símbolo: `#6435E7 → #9147FF`

O sistema **Vizantu Planos** usa a versão branca como marca d'água ("Plano criado por Vizantu") em todo plano enviado ao cliente — os arquivos servidos ficam em `public/brand/` daquele repositório.
